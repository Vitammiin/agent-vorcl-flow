# Навык: Tailwind CSS

Utility-first стилизация по официальной документации Tailwind.

## Основы
- Стилизуй утилитами прямо в разметке; избегай кастомного CSS, где есть утилита.
- Повторяющиеся паттерны — извлекай в **компоненты**, а не в `@apply`-классы.
- Дизайн-токены (цвета, spacing, радиусы, шрифты) — в конфиге темы; используй семантические токены, не «магические» значения.

## Варианты и композиция
- Варианты компонента — через **cva** (`class-variance-authority`); объединение классов — `clsx`/`tailwind-merge` (`cn`).
- Условные классы — через `cn(...)`, без конкатенации строк с дублями.

## Адаптивность и темы
- Mobile-first: базовые утилиты + брейкпоинты `sm: md: lg:`.
- Тёмная тема — `dark:`; предпочитай CSS-переменные для токенов, переключаемых по теме.
- Состояния — `hover: focus-visible: disabled: aria-*:` варианты.

## Доступность
- `focus-visible` вместо снятия обводки; достаточный контраст (WCAG); не полагайся только на цвет.
- Скрытие для зрячих, но не для скринридеров — `sr-only`.

## Совет
- Порядок утилит и дубли держи в узде плагином `prettier-plugin-tailwindcss`.
