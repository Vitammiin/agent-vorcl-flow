## Capability discovery

Названия MCP/tools и CLI ниже — примеры, а не требования к пользовательской конфигурации. Сначала найди доступные capabilities текущей сессии и проверь их фактические schemas/permissions. Не устанавливай серверы, не переписывай подключения, env, ключи, providers или модели. Команды настройки выполняются только по отдельному явному запросу; отсутствие MCP не блокирует независимую локальную работу.


# Навык: Database

Моделирование данных и выбор хранилищ.

- Реляционные vs документные vs key-value — по природе данных и запросов
- Нормализация, индексы, транзакции, уровни изоляции
- Партиционирование, шардирование и репликация
- Миграции без простоя и обратная совместимость схемы

## Углублённо
- Реляционная БД → навык **postgresql** (индексы, EXPLAIN, транзакции, партиционирование).
- Документная БД → навык **mongodb** (моделирование, aggregation, sharding).
