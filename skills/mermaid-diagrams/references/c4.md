# C4

Архитектура по модели C4 — контекст системы, контейнеры, компоненты, динамика вызовов и развёртывание; синтаксис совместим с C4-PlantUML. **Не применять**, когда нужен автолейаут или произвольный граф: C4 в mermaid помечен как **экспериментальный** (синтаксис и свойства могут меняться), раскладка задаётся порядком строк, а не алгоритмом — для свободных схем берите `flowchart` или `architecture-beta`.

## Минимальный скелет

```mermaid
C4Context
    title Контекст системы
    Person(user, "Пользователь", "Клиент банка")
    System(app, "Интернет-банк", "Просмотр счетов и платежи")
    Rel(user, app, "Использует", "HTTPS")
```

## Синтаксис

### Пять типов диаграмм

Тип задаётся первой строкой, `title <текст>` — необязательный заголовок.

| Заголовок | Уровень C4 |
| --- | --- |
| `C4Context` | System Context — система и её окружение |
| `C4Container` | Container — приложения/хранилища внутри системы |
| `C4Component` | Component — компоненты внутри контейнера |
| `C4Dynamic` | Dynamic — пронумерованная последовательность вызовов |
| `C4Deployment` | Deployment — узлы развёртывания и что на них крутится |

Элементы, границы и связи из разных уровней синтаксически доступны в любом типе (в `C4Component` штатно используются `Container(...)` и `System_Ext(...)` для окружения).

### Элементы уровня Context: Person и System

Сигнатуры: `Person(alias, label, ?descr, ?sprite, ?tags, $link)`, `System(alias, label, ?descr, ?sprite, ?tags, $link)`.

Варианты: суффикс `_Ext` — внешний (серая заливка), `Db` — цилиндр (хранилище), `Queue` — очередь.

```mermaid
C4Context
    title Элементы уровня Context
    Person(p, "Оператор", "Сотрудник поддержки")
    Person_Ext(pe, "Клиент", "Внешний пользователь")
    System(s, "Ядро", "Основная система")
    System_Ext(se, "Почта", "Внешний SMTP")
    SystemDb(sdb, "Хранилище", "База данных системы")
    SystemDb_Ext(sdbe, "Мейнфрейм", "Внешнее хранилище")
    SystemQueue(sq, "Очередь", "Внутренняя шина")
    SystemQueue_Ext(sqe, "Kafka", "Внешняя шина")
    Rel(pe, s, "Обращается")
    Rel(s, sdb, "Читает и пишет")
```

### Container

`Container(alias, label, ?techn, ?descr, ?sprite, ?tags, $link)` — **третий аргумент здесь технология, а не описание** (в отличие от `System`). Варианты: `ContainerDb`, `ContainerQueue`, `Container_Ext`, `ContainerDb_Ext`, `ContainerQueue_Ext`.

```mermaid
C4Container
    title Контейнеры интернет-банка
    Person(customer, "Клиент", "Клиент банка")
    System_Ext(email, "Почтовая система", "Внешний Exchange")

    Container_Boundary(c1, "Интернет-банк") {
        Container(spa, "SPA", "JavaScript, Angular", "Весь функционал через браузер")
        Container_Ext(mobile, "Мобильное приложение", "C#, Xamarin", "Подмножество функций")
        Container(web, "Веб-приложение", "Java, Spring MVC", "Отдаёт статику и SPA")
        ContainerDb(db, "База данных", "SQL", "Регистрации, хэши паролей, логи")
        ContainerQueue(mq, "Очередь событий", "RabbitMQ", "Асинхронные уведомления")
        ContainerDb_Ext(dwh, "Витрина", "ClickHouse", "Внешняя аналитика")
        ContainerQueue_Ext(bus, "Шина", "Kafka", "Внешние события")
    }

    Rel(customer, web, "Использует", "HTTPS")
    Rel(web, spa, "Отдаёт")
    Rel(spa, db, "Читает", "JDBC")
    Rel_Back(db, mq, "Публикует события")
    Rel(mq, email, "Отправляет письма", "SMTP")
    UpdateRelStyle(customer, web, $offsetY="60", $offsetX="90")
```

### Component

`Component(alias, label, ?techn, ?descr, ?sprite, ?tags, $link)` плюс `ComponentDb`, `ComponentQueue`, `Component_Ext`, `ComponentDb_Ext`, `ComponentQueue_Ext`.

```mermaid
C4Component
    title Компоненты API-приложения
    Container(spa, "SPA", "JavaScript и Angular", "Функционал в браузере")
    ContainerDb(db, "База данных", "Реляционная СУБД", "Учётные записи и логи")
    System_Ext(mbs, "Мейнфрейм", "Ядро банковских данных")

    Container_Boundary(api, "API Application") {
        Component(sign, "Sign In Controller", "MVC Rest Controller", "Вход пользователей")
        Component(security, "Security Component", "Spring Bean", "Пароли и сессии")
        ComponentDb(cache, "Cache", "Redis", "Кэш сессий")
        ComponentQueue(events, "Events", "Spring AMQP", "Исходящие события")
        Component_Ext(sso, "SSO Adapter", "OIDC", "Внешний провайдер")
        Rel(sign, security, "Использует")
        Rel(security, cache, "Читает и пишет")
        Rel(security, sso, "Проверяет токен")
        Rel(security, db, "Читает и пишет", "JDBC")
        Rel(events, mbs, "Отправляет", "XML/HTTPS")
    }

    Rel_Back(spa, sign, "Использует", "JSON/HTTPS")
    UpdateRelStyle(spa, sign, $offsetY="-40")
    UpdateRelStyle(security, db, $offsetY="-40")
```

### Границы

Открывающая скобка `{` идёт в той же строке, закрывающая `}` — на своей. Вложенность произвольная.

- `Boundary(alias, label, ?type, ?tags, $link)` — универсальная; `type` печатается меткой типа границы.
- `Enterprise_Boundary(alias, label, ?tags, $link)`
- `System_Boundary(alias, label, ?tags, $link)`
- `Container_Boundary(alias, label, ?tags, $link)`

```mermaid
C4Context
    title Вложенные границы
    Enterprise_Boundary(b0, "Банк") {
        Person(customer, "Клиент", "Клиент банка")
        System(core, "Интернет-банк", "Счета и платежи")

        Enterprise_Boundary(b1, "Внутренний периметр") {
            SystemDb_Ext(mainframe, "Мейнфрейм", "Ядро банковских данных")

            System_Boundary(b2, "Продуктовые системы") {
                System(sysA, "Система A")
                System(sysB, "Система B", "Персональные счета")
            }

            Boundary(b3, "Асинхронный контур", "boundary") {
                SystemQueue(q1, "Очередь платежей", "Внутренняя шина")
                SystemQueue_Ext(q2, "Внешняя очередь", "Партнёрская шина")
            }
        }
    }

    BiRel(customer, core, "Использует")
    Rel(core, mainframe, "Читает", "MQ")
    Rel(core, q1, "Публикует")
    UpdateLayoutConfig($c4ShapeInRow="3", $c4BoundaryInRow="1")
```

### Deployment

- `Deployment_Node(alias, label, ?type, ?descr, ?sprite, ?tags, $link)`
- `Node(...)` — короткий псевдоним `Deployment_Node`
- `Node_L(...)` — выравнивание влево, `Node_R(...)` — вправо

Узлы вкладываются друг в друга и содержат `Container*`.

```mermaid
C4Deployment
    title Развёртывание интернет-банка
    Deployment_Node(mob, "Устройство клиента", "iOS или Android") {
        Container(mobile, "Мобильное приложение", "Xamarin", "Подмножество функций банка")
    }

    Deployment_Node(comp, "Компьютер клиента", "Windows или macOS") {
        Deployment_Node(browser, "Браузер", "Chrome, Firefox,<br/> Safari или Edge") {
            Container(spa, "SPA", "JavaScript и Angular", "Функционал в браузере")
        }
    }

    Deployment_Node(plc, "Дата-центр банка", "Big Bank plc") {
        Node_L(api_node, "bigbank-api x8", "Ubuntu 22.04") {
            Node(tomcat, "Apache Tomcat", "Tomcat 10.x") {
                Container(api, "API Application", "Java и Spring MVC", "JSON/HTTPS API")
            }
        }
        Node_R(db_node, "bigbank-db01", "Ubuntu 22.04") {
            Node(pg, "PostgreSQL — Primary", "PostgreSQL 16") {
                ContainerDb(db, "База данных", "Реляционная схема", "Учётные записи и логи")
            }
        }
    }

    Rel(mobile, api, "Вызовы API", "json/HTTPS")
    Rel(spa, api, "Вызовы API", "json/HTTPS")
    Rel(api, db, "Читает и пишет", "JDBC")
    UpdateRelStyle(spa, api, $offsetY="-40")
    UpdateRelStyle(api, db, $offsetY="-20", $offsetX="5")
```

### Dynamic

Связи нумеруются **в порядке их записи**. `RelIndex(index, from, to, label, ?tags, $link)` принимается ради совместимости с C4-PlantUML, но параметр `index` игнорируется.

```mermaid
C4Dynamic
    title Динамика входа в систему
    ContainerDb(c4, "База данных", "Реляционная схема", "Учётные записи и логи")
    Container(c1, "SPA", "JavaScript и Angular", "Функционал в браузере")
    Container_Boundary(b, "API Application") {
        Component(c3, "Security Component", "Spring Bean", "Пароли и сессии")
        Component(c2, "Sign In Controller", "Spring MVC Rest Controller", "Вход пользователей")
    }
    Rel(c1, c2, "Отправляет учётные данные", "JSON/HTTPS")
    Rel(c2, c3, "Вызывает isAuthenticated()")
    RelIndex(3, c3, c4, "select * from users where username = ?", "JDBC")

    UpdateRelStyle(c1, c2, $textColor="red", $offsetY="-40")
    UpdateRelStyle(c2, c3, $textColor="red", $offsetX="-40", $offsetY="60")
    UpdateRelStyle(c3, c4, $textColor="red", $offsetY="-40", $offsetX="10")
```

### Связи

`Rel(from, to, label, ?techn, ?descr, ?sprite, ?tags, $link)`.

| Форма | Смысл |
| --- | --- |
| `Rel` | обычная направленная связь |
| `BiRel` | двусторонняя связь |
| `Rel_U` / `Rel_Up` | подсказка «вверх» |
| `Rel_D` / `Rel_Down` | подсказка «вниз» |
| `Rel_L` / `Rel_Left` | подсказка «влево» |
| `Rel_R` / `Rel_Right` | подсказка «вправо» |
| `Rel_Back` | стрелка в обратную сторону |
| `RelIndex` | как `Rel`, индекс игнорируется |

```mermaid
C4Context
    title Формы связей
    System(a, "A")
    System(b, "B")
    System(c, "C")
    System(d, "D")
    System(e, "E")
    Rel_U(a, b, "вверх")
    Rel_D(a, c, "вниз")
    Rel_L(a, d, "влево")
    Rel_R(a, e, "вправо")
    Rel_Back(b, c, "обратная стрелка")
    BiRel(d, e, "двусторонняя")
```

### Стилизация и раскладка

Пишутся **в конце** диаграммы:

- `UpdateElementStyle(elementName, ?bgColor, ?fontColor, ?borderColor, ?shadowing, ?shape, ?sprite, ?techn, ?legendText, ?legendSprite)` — меняет стиль элемента, отдельной записи легенды не создаёт.
- `UpdateRelStyle(from, to, ?textColor, ?lineColor, ?offsetX, ?offsetY)` — цвет связи и **смещение подписи** относительно исходной позиции.
- `UpdateLayoutConfig(?c4ShapeInRow, ?c4BoundaryInRow)` — сколько фигур в ряду (по умолчанию `4`) и сколько границ в ряду (по умолчанию `2`).

Параметры с `?` задаются **позиционно** либо **именованно** через `$`; формы эквивалентны:

```mermaid
C4Context
    title Позиционные и именованные параметры
    Person(customerA, "Клиент")
    System(bankA, "Банк")
    System(bankB, "Партнёр")
    Rel(customerA, bankA, "Использует")
    Rel(customerA, bankB, "Использует")
    UpdateElementStyle(customerA, $bgColor="grey", $fontColor="red", $borderColor="red", $shadowing="true", $legendText="клиент")
    UpdateRelStyle(customerA, bankA, "red", "blue", "-40", "60")
    UpdateRelStyle(customerA, bankB, $textColor="red", $lineColor="blue", $offsetX="-40", $offsetY="60")
    UpdateLayoutConfig("3", "1")
```

### Перенос текста в элементе

По умолчанию текст элемента (имя, тип, описание) остаётся в одну строку, а элемент растягивается по самой длинной строке. Корневой конфиг `wrap: true` включает перенос по ширине элемента, ширина задаётся `c4.width`.

```mermaid
---
config:
  wrap: true
  c4:
    width: 216
---
C4Context
    title Перенос текста
    Person(u, "Пользователь", "Очень длинное описание, которое переносится по ширине элемента")
    System(s, "Система", "Тоже довольно длинное описание элемента системы")
    Rel(u, s, "Использует")
```

Ручной перенос — тег `<br/>` внутри подписи.

### Accessibility

`accTitle:` и `accDescr:` поддерживаются (проверено рендером на 11.16.1):

```mermaid
C4Context
    accTitle: Контекстная диаграмма интернет-банка
    accDescr: Клиент взаимодействует с системой интернет-банка
    title Контекст системы
    Person(u, "Пользователь")
    System(s, "Интернет-банк")
    Rel(u, s, "Использует")
```

### Что НЕ поддерживается

Разбирается парсером, но игнорируется или не реализовано:

- `sprite`, `tags`, `link`, автоматическая **Legend** — не реализованы (аргументы `$tags=` / `$link=` синтаксически принимаются и ничего не рисуют).
- `AddElementTag(...)`, `AddRelTag(...)` — нет.
- `RoundedBoxShape()`, `EightSidedShape()`, `DashedLine()`, `DottedLine()`, `BoldLine()` — нет.
- Раскладочные операторы `Lay_U`/`Lay_Up`, `Lay_D`/`Lay_Down`, `Lay_L`/`Lay_Left`, `Lay_R`/`Lay_Right` — **не поддерживаются и поддерживаться не планируют**; на 11.16.1 `Lay_U(a, b)` даёт лексическую ошибку и ломает всю диаграмму. Позицию фигур меняют порядком строк и `UpdateLayoutConfig`.

## Ловушки

- **`Lay_*` ломает рендер** — лексическая ошибка (проверено на 11.16.1). Порядок фигур задаётся только порядком объявлений.
- **Раскладка не автоматическая.** Переставляйте строки и крутите `UpdateLayoutConfig($c4ShapeInRow, $c4BoundaryInRow)`, а подписи связей двигайте `$offsetX`/`$offsetY` — иначе они наезжают на стрелки.
- **Третий аргумент разный у разных элементов**: у `System`/`Person` это описание, у `Container`/`Component` — технология, у `Boundary`/`Deployment_Node` — тип. Перепутанные аргументы не ломают рендер, но подписывают элемент неверно.
- **`UpdateElementStyle` / `UpdateRelStyle` только для уже объявленных элементов** и пишутся в конце диаграммы; `updateElementStyle` со строчной буквы — это исторический алиас, который обновляет стиль **связи**, а не элемента, включая смещение подписи. Не используйте его.
- **Цвета C4 фиксированы**: диаграмма не подхватывает темы/скины, разного CSS под разные темы нет — красьте только через `Update*Style`.
- **`\n` не работает** — перенос строки только `<br/>`.
- **Экспериментальный статус**: синтаксис и свойства могут измениться в следующих релизах, пиньте версию mermaid.
