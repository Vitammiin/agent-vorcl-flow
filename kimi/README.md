# Agent-Vorcl-Flow для Kimi CLI

Адаптер устанавливает skills в `~/.kimi/skills` и файлы custom agents с префиксом `avf-` в `~/.kimi/agents`. Агент расширяет профиль `default`, сохраняя настройки среды пользователя.

```bash
npx github:Vitammiin/agent-vorcl-flow --kimi --dry-run
npx github:Vitammiin/agent-vorcl-flow --kimi
```

Для другого каталога задайте абсолютный `KIMI_HOME`. Без флагов установщик показывает справку; `--all` явно выбирает все адаптеры. После установки откройте новую сессию Kimi.

```bash
kimi --agent-file ~/.kimi/agents/avf-expo-mobile.yaml
```

```text
/skill:vorcl добавить экран истории операций
/skill:expo-mobile-create-screen экран транзакций
/skill:expo-mobile-audit
```

Workflow работает с планом и проверками текущего чата. Task Master — дополнительный инструмент по явному выбору пользователя. При отсутствии независимых субагентов проверка выполняется отдельным проходом с честным указанием этого ограничения.

Установщик не меняет `mcp.json`, `config.toml`, hooks, секреты или состояние Task Master. Используются MCP и другие инструменты, которые пользователь уже подключил в своей среде. Guards можно вызывать вручную из установленных skills, когда они нужны задаче.

Повторная установка обновляет только неизменённые компоненты из `.agent-vorcl-flow-install.json`. Чужие компоненты, пользовательские изменения и старые установки без реестра владения сохраняются.

```bash
npx github:Vitammiin/agent-vorcl-flow --check-legacy
```

Эта проверка только сообщает пути прежних настроек и сервисов. Удаление и перенос описаны в [руководстве по миграции](../docs/MIGRATION.md).
