# Навык: Tailwind CSS

Utility-first стилизация по официальной документации Tailwind.

## Основы
- Стилизуй утилитами; избегай кастомного CSS, где есть утилита.
- Повторяющиеся паттерны — в **компоненты**, не в `@apply`.
- Дизайн-токены (цвета, spacing, радиусы, шрифты) — в конфиге темы; семантические токены, не «магия».

## Варианты и композиция
- Варианты — через **cva** (`class-variance-authority`); объединение — `clsx`/`tailwind-merge` (`cn`).

## Адаптивность и темы
- Mobile-first + брейкпоинты `sm: md: lg:`.
- Тёмная тема — `dark:`; CSS-переменные для токенов.
- Состояния — `hover: focus-visible: disabled: aria-*:`.

## Доступность
- `focus-visible` вместо снятия обводки; контраст (WCAG); не только цвет; `sr-only`.

## Совет
- Порядок утилит — `prettier-plugin-tailwindcss`.
