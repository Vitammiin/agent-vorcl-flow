# Задача: заявка на правку и делегирование (pinpoint)

Собери заявку на правку существующего кода и передай доменной роли (см. `$ui-source-mapping`). По карте «скриншот → исходники» (экран, маршрут, контрол, логика) сформулируй **точечную** заявку: что менять в **уже существующих** файлах (`file:line`), не создавая новых компонентов/файлов и переиспользуя существующие обработчик/стиль/стор. Определи область (Frontend/Backend), заведи задачу(и) `add_task` (`$task-master`) и делегируй: UI — `$frontend`, серверную логику — `$backend`, данные/БД — `$database`; цикл (`next_task` → реализация → `testStrategy` → `set_task_status done`) веди сам. Сам код не правишь. Опирайся на `$ui-source-mapping`, `$frontend-architecture`, `$workflow`, `$task-master`.
