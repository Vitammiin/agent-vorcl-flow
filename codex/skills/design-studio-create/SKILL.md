# Создание артефакта

Используй `$design-studio`, `system-prompt.md` и matching project type. Для UI загрузи `hi-fi-design.md`, а для интерактивности — `interactive-prototype.md`. Сохрани результат в `designs/<project>/`, запусти localhost preview и исправь ошибки.
