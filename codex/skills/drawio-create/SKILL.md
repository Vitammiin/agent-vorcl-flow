# Задача: построить диаграмму по описанию (drawio)

Построй диаграмму draw.io по описанию (см. `$drawio-diagrams`, `$system-design`).

Выбери тип под задачу: процесс → flowchart, роли/отделы → swimlane, система → network/cloud, данные → ERD, иерархия → org chart, идеи → mind map, бизнес-процесс → BPMN, объекты/поведение → UML.

Требования: нативный `mxGraphModel`; уникальные id (`0`/`1` зарезервированы); у каждого ребра реальные `source`/`target`; ортогональные рёбра; выравнивание по сетке (`gridSize=10`, без наложений); семантические цвета; экранирование `&`/`<`/`"`. Сохрани в `.drawio`, проверь `xmllint --noout`. Отдай путь + как открыть в app.diagrams.net + какие custom-библиотеки (`?clibs=`) включить + заметки о допущениях. Опирайся на `$drawio-diagrams`, `$system-design`.
