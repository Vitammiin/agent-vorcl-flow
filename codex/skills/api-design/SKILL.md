# Навык: API Design

Проектирование программных интерфейсов.

- REST / GraphQL / gRPC — когда что уместно
- Версионирование, идемпотентность, пагинация, лимиты запросов
- Контракты, коды ошибок, обратная совместимость
- Безопасность: аутентификация, авторизация, rate limiting

## Углублённо
- Контракты и OpenAPI-покрытие → навык **swagger-coverage**.
- Коды и обработка ошибок → навык **error-handling**.
- Локализация ответов (i18n) → навык **i18n**: контракт ошибок — стабильный машинный `code` + параметры (не готовый переведённый текст), выбор языка по `Accept-Language`/локали пользователя.
