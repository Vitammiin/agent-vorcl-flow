# Visual evidence research

1. Открой изображение и зафиксируй только видимые домен, бренд, строки, функции, значения и состояние UI.
2. Сформируй до трёх кандидатов по уникальным строкам. Не полагайся лишь на цвета/layout.
3. Подтверди официальный домен, терминологию и документацию; проверь typosquatting/phishing.
4. Проверь актуальное состояние через `$web-scraping`: CLI → MCP → REST/keyless.
5. Раздели наблюдение, docs, live data и вывод. Дай прямые URL, время проверки, ограничения и уверенность.

Высокая уверенность требует официального домена и двух специфичных совпадений. Login/CAPTCHA не обходи. Формы, auth, publish, purchase и destructive controls не активируй без подтверждения. Не используй этот навык для генерации UI-кода.
