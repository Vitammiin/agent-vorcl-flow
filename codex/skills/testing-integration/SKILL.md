# Задача: интеграционные тесты

Напиши интеграционные тесты (см. `$testing-strategy`, `$nodejs`, `$error-handling`).

1. Стек по `package.json`: Fastify → `app.inject()`, Express/прочее → `supertest`; раннер — существующий.
2. API: подними приложение в тесте, проверь статус/тело/заголовки; негативные кейсы обязательны (400/401/403/404).
3. БД: testcontainers или отдельная тестовая БД/копия; НИКОГДА не dev/prod-база.
4. Изоляция: каждый тест сам создаёт данные и убирает за собой (rollback/truncate) — независимость от порядка.
5. Мокай только внешние сервисы (сторонние API, почта, платежи); свою БД и слои — нет.
6. Прогони набор и вставь вывод раннера. Docker недоступен — скажи явно и предложи тестовую БД, не имитируй прогон.
