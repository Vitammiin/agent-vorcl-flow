# Задача: доработать Mermaid

Доработай существующий `.mmd` (см. `$mermaid-diagrams`, `$mermaid-rendering`).

Прочитай диаграмму, пойми тип, внеси точечные правки: сменить направление (`TD`↔`LR`), сгруппировать в `subgraph`, добавить цвета `classDef`/`class`, переименовать/добавить/убрать узлы и связи, разбить перегруженный граф. Не ломай остальное.

Требования: кавычки для подписей со спецсимволами, парные `subgraph … end`. После правок **обязательно** прогони через реальный рендер (`mcp-mermaid`/`mmdc`) и устрани ошибки. Дай обновлённый `.mmd` + результат рендер-теста + список изменений.
