# Задача: оптимизация производительности

Найди и устрани узкие места производительности в том, что описал пользователь.

Оптимизация без измерений — гадание: сначала цифры «до», потом правка по данным, потом те же цифры «после» на той же нагрузке.

1. Измерь базовую линию: время ответа/запроса (`autocannon`, `curl -w`, `EXPLAIN ANALYZE` для SQL, профайлер Node для CPU); зафиксируй конкретные числа.
2. Найди первопричину по данным: N+1 и отсутствующие индексы (`$postgresql`), лишние запросы, отсутствие кэша (`$redis`), блокировка event loop (`$nodejs`).
3. Применяй меры по одной: индекс, кэш с TTL и инвалидацией, батчинг, пагинация — каждую с оценкой ожидаемого эффекта до применения.
4. Доказательство: повтори замер из шага 1 и покажи таблицу «до → после» (ms / RPS / строки плана запроса); правку без измеримого выигрыша откати.
5. Убедись, что поведение не изменилось: тесты зелёные, вывод покажи.

Если цель не указана — спроси, что именно тормозит (эндпоинт, запрос, джоба), или начни с самых медленных запросов в логах. Если узкое место вне бэкенда (фронт, сеть, сторонний API) — скажи честно и укажи, куда копать.

Опирайся на `$postgresql`, `$redis`, `$nodejs`.
