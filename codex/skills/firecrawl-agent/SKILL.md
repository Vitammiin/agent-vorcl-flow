# Firecrawl Agent

Используй agent лишь когда search/scrape недостаточно. Проверь CLI help, иначе MCP/актуальный REST. До запуска зафиксируй scope, output, max credits/cost и stop condition; без лимита получи подтверждение. Отслеживай реальный job ID, сохраняй output и sources в `.firecrawl/`.
