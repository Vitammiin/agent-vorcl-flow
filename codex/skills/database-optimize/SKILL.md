# Задача: оптимизация БД (database)

Оптимизируй работу с БД (см. `$database`).

Сначала измерь: план запроса `EXPLAIN (ANALYZE, BUFFERS)` (Postgres; `ANALYZE` выполняет оператор — для DML оборачивай в транзакцию с `ROLLBACK`) / `explain` и отлов **COLLSCAN** (MongoDB). Затем: недостающие/неоптимальные индексы (составные — порядок колонок, частичные, покрывающие; TTL-индексы — только в Mongo), устранение **N+1** (джойн/`IN`/`$lookup`/dataloader), пагинация **keyset/seek** вместо `OFFSET`, лишние/дублирующие индексы (стоимость записи), горячие ключи Redis и стратегия кэша. Дай конкретную починку и подтверди эффект повторным планом/замером. Изменения индексов на проде — как миграция, с подтверждением. Опирайся на `$postgresql`, `$mongodb`, `$redis`, `$database`.
