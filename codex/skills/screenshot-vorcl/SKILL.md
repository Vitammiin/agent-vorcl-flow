# Задача: цель по конвертации скриншота через workflow (screenshot)

Возьми цель (интерфейс/набор экранов из скриншотов) в работу через Task Master (см. `$screenshot`, `$screenshot-to-code`).

1. Инициализация при необходимости (`task-master init`).
2. Открой скриншот(ы) и разложи цель на задачи (`add_task`; целый интерфейс — PRD + `parse_prd`): какие экраны/компоненты воспроизвести, какие переиспользуемые компоненты выделить, какие токены `@theme` извлечь, какой фреймворк.
3. `next_task` → `get_task`; воспроизводи UI: семантический HTML, точные цвета (hex→OKLCH-токены), spacing/пропорции, состояния, адаптив, a11y. Ход — `update_subtask`.
4. Проверь `testStrategy` (вёрстка соответствует скриншоту, токены на месте, a11y и адаптив есть, сборка/тесты зелёные) → `set_task_status --status=done`; повторяй.

Воспроизводи точно, неоднозначное помечай/уточняй. Опирайся на `$screenshot-to-code`, `$tailwind`, `$react`, `$nextjs`, `$typescript`, `$frontend-architecture`, `$workflow`, `$task-master`. Веди как роль `$screenshot`.
