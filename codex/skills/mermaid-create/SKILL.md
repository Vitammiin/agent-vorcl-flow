# Задача: построить Mermaid по описанию

Построй Mermaid-диаграмму по описанию (см. `$mermaid-diagrams`, `$system-design`).

Выбери тип: процесс → flowchart, время → sequenceDiagram, данные → erDiagram, классы → classDiagram, состояния → stateDiagram-v2, план → gantt, ветки → gitGraph, идеи → mindmap, инфраструктура → architecture-beta, C4 → C4Context, доска → kanban, метрики → xychart/radar-beta/quadrantChart.

**Синтаксис бери из справочника, не из памяти:** таблица «задача → тип → справочник» в `$mermaid-diagrams`, затем `references/<тип>.md` (дистиллят официальных доков mermaid, проверенный рендером).

Требования: точный заголовок (`flowchart TD`, не `lowchart`); направление осознанно; подписи со спецсимволами → в кавычки `["..."]`; парные `subgraph … end`; семантические цвета `classDef`. **Обязательно** прогони через реальный рендер (`mcp-mermaid`/`mmdc`) и устрани ошибки до выдачи. Затем, если можешь прочитать картинку, посмотри на неё: обрезанные подписи, слипшаяся плотность, спагетти связей, пропорции, контраст, подходит ли тип — максимум два круга правок с повторным рендером. Сохрани `.mmd` + рендер, дай путь + результат рендер-теста + как посмотреть + допущения.
