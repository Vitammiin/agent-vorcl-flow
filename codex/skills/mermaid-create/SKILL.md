# Задача: построить Mermaid по описанию

Построй Mermaid-диаграмму по описанию (см. `$mermaid-diagrams`, `$system-design`).

Выбери тип: процесс → flowchart, время → sequenceDiagram, данные → erDiagram, классы → classDiagram, состояния → stateDiagram-v2, план → gantt, ветки → gitGraph, идеи → mindmap.

Требования: точный заголовок (`flowchart TD`, не `lowchart`); направление осознанно; подписи со спецсимволами → в кавычки `["..."]`; парные `subgraph … end`; семантические цвета `classDef`. **Обязательно** прогони через реальный рендер (`mcp-mermaid`/`mmdc`) и устрани ошибки до выдачи. Сохрани `.mmd` + рендер, дай путь + результат рендер-теста + как посмотреть + допущения.
