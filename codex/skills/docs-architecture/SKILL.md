# Задача: создать/обновить ARCHITECTURE.md

Создай или обнови `ARCHITECTURE.md` (см. `$system-design`, `$technical-writing`).

1. Прочитай реальную структуру: каталоги, workspaces, точки входа, роуты, модели/миграции. Описывай **по коду**; каждый упомянутый модуль/файл проверь на существование.
2. Разделы: обзор одним абзацем → модули и границы (таблица: модуль → ответственность → ключевые файлы) → data flow (запрос через слои до БД) → схема данных → интеграции → ключевые решения в ADR-формате (context/decision/consequences).
3. **Диаграммы не рисуй вслепую** — делегируй `$mermaid` (flowchart/erDiagram/sequence, валидация реальным рендером); изощрённые визуальные — `$drawio`. Ты формулируешь узлы/связи/границы, вставляешь результат mermaid-блоком или ссылкой.
4. Уровень детализации — по `$system-design`: границы, sync/async-связи, хранилища; не вываливай все файлы на одну схему. Счётчики — пересчётом реальных каталогов.

Отдай путь к файлу + список диаграмм с рендер-статусом + сверку упомянутых модулей с реальностью.
