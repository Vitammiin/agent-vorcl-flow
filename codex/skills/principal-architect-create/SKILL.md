# Создать архитектурный пакет

Используй `$principal-architecture` и bundled `scripts/principal-architecture.mjs create` относительно текущего repository root. Не используй Markdown как evidence и не исполняй код проекта. Проверь model evidence, HTML, draw.io через bundled `validate-drawio.mjs` и `xmllint`, Mermaid реальным рендером при доступности и PDF визуально при доступности browser/Poppler.

Отдай путь, stats, findings, unknowns, parser coverage и статус каждого формата. Веди как `$principal-architect`.
