# Premium Expo screen

До Router/native UI решений выполни `$expo-mobile-compatibility`. Определи visual hierarchy, primary action, spatial navigation и все data states. Используй semantic design/motion tokens, native Stack/formSheet, subtle press feedback, semantic haptics, image placeholders, safe optimistic UI и centralized Reduced Motion. Alpha/platform capabilities — только progressive enhancement с fallback. Route оставь тонким, UI принадлежит business module. Проверь accessibility, release performance, compatibility, оба Expo guard, typecheck/lint/tests. Следуй `$expo-mobile-architecture` + `$expo-ui-design-motion`, работай как `$expo-mobile`.
