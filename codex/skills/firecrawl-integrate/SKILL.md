# Firecrawl app integration

Используй upstream `firecrawl-build` и подходящий `firecrawl-build-*`. Если их нет, предложи `$firecrawl-setup`; устанавливай только после подтверждения. Изучи стек, выбери endpoint/SDK, храни `FIRECRAWL_API_KEY` в env и не коммить его. Реализуй smoke request и обработку ошибок.
