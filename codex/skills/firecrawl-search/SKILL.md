# Firecrawl search

Следуй `$web-scraping`: CLI search после `--help` → MCP → REST `/v2/search`. При слабых сниппетах скрейпни выбранные результаты. Сохрани отчёт в `.firecrawl/`, процитируй URL и сверь ключевые факты по двум источникам.
