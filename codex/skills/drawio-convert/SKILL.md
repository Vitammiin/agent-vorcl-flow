# Задача: конвертировать исходник в диаграмму (drawio)

Конвертируй указанный исходник в диаграмму draw.io (см. `$drawio-diagrams`, `$system-design`, `$pmp-diagrams`).

Прочитай исходник и выбери отображение: схема БД → ERD (таблицы-swimlane, PK/FK, кардинальность); структура папок → дерево; код (классы/роуты) → UML class/sequence; mermaid/CSV/JSON → эквивалентная диаграмма. Сохрани семантику исходника (все сущности/связи; недостающее помечай, не выдумывай).

Требования: валидный `mxGraphModel`, уникальные id, у рёбер реальные `source`/`target`, ортогональные рёбра, сетка, семантические цвета. Сохрани в `.drawio`, `xmllint --noout`. Отдай путь + как открыть + какие библиотеки включить + заметки о пропусках. Опирайся на `$drawio-diagrams`, `$system-design`, `$pmp-diagrams`.
