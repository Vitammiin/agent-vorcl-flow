# Задача: создать/обновить README

Создай или обнови README (см. `$technical-writing`).

1. Изучи реальность: `package.json` (`scripts`, `engines`), lock-файл, структура, точки входа, `.env.example` — README описывает то, что есть в коде сейчас.
2. Структура: лид «что это и зачем» (без воды) → Quickstart (минимум шагов до работающего) → Usage → Configuration (таблица env/опций из кода) → Troubleshooting → лицензия.
3. **Каждый пример прогони** или сверь со `scripts`; флаги/env — грепом по коду. Пример работает копипастом; плейсхолдеры — явные `<...>`. Счётчики/версии — из реальных файлов. Относительные ссылки — проверь существование целей.
4. README на других языках — синхронизируй паритет: те же секции и факты, кодовые блоки идентичны (код не переводится), взаимные ссылки-переключатели.

По умолчанию — корневой `README.md`; существующий не переписывай стилистически без запроса — чини дрейф. Отдай путь + доказательства проверки примеров + статус паритета.
