# Задача: конвертировать исходник в Mermaid

Конвертируй исходник в Mermaid (см. `$mermaid-diagrams`, `$system-design`).

Определи тип: схема БД (Prisma/SQL DDL) → erDiagram; классы/типы → classDiagram; вызовы/роуты → sequenceDiagram; структура папок/пайплайн → flowchart; `.drawio`/CSV/JSON → подходящий тип. Прочитай исходник, извлеки сущности и связи, не выдумывай — помечай допущения.

Требования: валидный синтаксис под тип; кардинальности ERD (`||--o{`); подписи со спецсимволами → в кавычки. **Обязательно** прогони через реальный рендер (`mcp-mermaid`/`mmdc`) и устрани ошибки до выдачи. **Материализуй** результат как `.mmd`-файл (+ рендер SVG/PNG по запросу) в рабочем каталоге пользователя — не только текстом в ответе; **только прошедший рендер артефакт = готово**. Дай пути к файлам + результат рендер-теста + что выведено из исходника и что помечено допущением.
