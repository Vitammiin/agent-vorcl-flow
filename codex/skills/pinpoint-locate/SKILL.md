# Задача: найти экран/компонент по скриншоту (pinpoint)

Найди в существующем коде экран со скриншота (см. `$ui-source-mapping`). Сначала подтверди, что это существующий проект; генерация нового UI — на `$screenshot-convert`.

Извлеки со скриншота **якоря**: видимый текст (заголовки, лейблы, плейсхолдеры, меню, тосты), иконки, тип блока, контекст маршрута. Ищи `rg` от самой редкой строки к частой; в мультиязычном проекте текст — **значение перевода**: грепни по локали → ключ → грепни ключ по компонентам (`$i18n`). Игнорируй `node_modules`; много совпадений — сузь по соседним якорям, ноль — проверь склейку строк/шаблоны/`data-testid`. Отдай привязку до **`file:line`** + фрагмент; неоднозначность — кандидаты с различием. **Только чтение** — ничего не создавай и не правь. Следующие шаги конвейера: маршрут — `$pinpoint-route`, контрол — `$pinpoint-control`, логика — `$pinpoint-trace`. Опирайся на `$ui-source-mapping`, `$screenshot-to-code`, `$frontend-architecture`, `$react`, `$nextjs`, `$i18n`.
