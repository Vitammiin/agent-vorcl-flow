# Firecrawl support ask

Собери реальный jobId, endpoint, безопасные параметры, status и error. Проверь CLI help; иначе MCP или POST `/v2/support/ask`. Не передавай секреты/PII. Верни ответ и fix parameters, но не повторяй мутацию без проверки и подтверждения.
