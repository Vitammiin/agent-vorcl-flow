# Задача: проверка типов

Проверь типы (**read-only**) в указанной области.

Запусти `tsc --noEmit` (и `eslint`, если есть) — только чтение. Найди: ошибки компилятора, `any`/`as any`/`@ts-ignore`, небезопасные касты (`as unknown as`), неявные `any`, рассинхрон zod-схем и типов, отсутствие exhaustive-проверок в `switch`. Помечай область (**Frontend** / **Backend**). Формат: `file:line`, что нашли, первопричина, конкретная починка; severity по влиянию. По значимым находкам — `add_task`. Опирайся на `$typescript`.
