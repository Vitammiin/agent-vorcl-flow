# Задача: грамотное логирование (resilience)

Расставь/выправи логирование в указанной области (см. `$error-handling`).

Структурные логи (JSON: pino/структурный logger), не голый `console.log` в проде. **Уровни:** `error` — сбой, требующий внимания; `warn` — аномалия с фолбэком; `info` — бизнес-события/границы запроса; `debug` — диагностика (в проде выкл./по флагу). **Логируй один раз** — на слое, где ошибка обрабатывается и есть контекст; пробрасывают выше — здесь не логируй (убери дубли). Поля: операция, ключевые id, `requestId`/correlation id, длительность важных операций, ошибка целиком (`stack`+`cause`). **Никогда** — пароли/токены/ключи/PII/полные чувствительные payload'ы (маскируй); на горячих путях сэмплируй. Логи не для управления потоком. Опирайся на `$error-handling`, `$nodejs`, `$backend-architecture`, `$react`.
