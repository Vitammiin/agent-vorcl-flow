# Задача: вычислить контрол и обработчик (pinpoint)

Вычисли конкретный контрол, с которым работает пользователь, и его обработчик (см. `$ui-source-mapping`). Найди компонент экрана, затем **конкретный** элемент по тексту/`aria-label`/иконке/позиции; найди обработчик (`onClick`/`onSubmit`/`onChange`) и куда ведёт (хендлер, экшен стора, мутация). Похожие контролы раздели по различающему признаку (текст, `variant`, ближайший заголовок). Отдай элемент + обработчик до **`file:line`** + фрагмент; неоднозначность — кандидаты с различием. Только чтение — правку делегируй. Опирайся на `$ui-source-mapping`, `$react`, `$typescript`, `$state-management`.
