# Задача: поимённый коммит

Закоммить изменения, относящиеся к задаче (см. `$git-workflow`). Рядом могут работать параллельные сессии — чужой WIP захватывать нельзя.

1. Сам выполни `git status --porcelain` и `git diff` — не доверяй пересказам.
2. Отбери ТОЛЬКО файлы задачи; незнакомые/несвязанные изменения — стоп и спроси владельца.
3. `git add <файл> <файл>` строго по именам. НИКОГДА `git add .`/`-A`.
4. Сообщение по Conventional Commits (`тип(scope): суть`; breaking — `!` + футер). Несвязанное — раздельными коммитами.
5. `git commit`, затем снова `git status` — покажи оба вывода (hash; чужой WIP нетронут). НЕ пушь без явного подтверждения.

Края: задача не задана — восстанови по diff и предложи разбивку; дерево чистое — так и скажи.
