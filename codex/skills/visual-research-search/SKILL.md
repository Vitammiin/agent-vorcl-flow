# Search from screenshot

Составь запросы из специфичных строк и признаков, выполни Firecrawl search. Отфильтруй клоны: официальный domain/docs/help/status/repository перед сторонними источниками. Верни страницу или кандидатов с URL и уверенностью; login не обходи.
