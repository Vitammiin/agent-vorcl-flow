# Добавить mobile API integration

Найди module-владельца. Добавь schema/DTO, API method, centralized query keys и query/mutation; validate response и map DTO. Переиспользуй `shared/api` для HTTP/auth/errors. Не вызывай API из screen и не копируй server data в Zustand. Проверь cache updates и data states. Следуй `$expo-mobile-architecture`, работай как `$expo-mobile`.
