# Firecrawl crawl

Сначала map, затем CLI crawl → MCP crawl/status → REST. Всегда задай limit/filters. Перед limit > 50 или всем сайтом покажи объём/стоимость и дождись подтверждения. Сохрани страницы и manifest с URL/job ID в `.firecrawl/`.
