# Задача: покрытие с находками

Сними покрытие и найди критичные дыры (см. `$testing-strategy`).

1. Запусти раннер с покрытием (`npx vitest run --coverage` / `npx jest --coverage`) — вставь итоговую таблицу.
2. Читай карту, а не общий процент: какие файлы и **ветки** не покрыты (branch важнее line).
3. Ранжируй по риску: деньги/авторизация/безопасность/запись данных → критично (~100% branch); домен → высоко; UI-обвязка/конфиг → низко.
4. Отчёт: топ непокрытых критичных мест (файл:строки, что за логика, чем грозит) + осмысленные `coverage.thresholds`, не «80% везде».
5. Проект под Task Master → `add_task` на закрытие критичных дыр (по одной на модуль, с testStrategy); иначе — список задач текстом.
6. Не поднимай цифру бессмысленными тестами (снапшоты всего, тесты геттеров). Покрытие не настроено — добавь `@vitest/coverage-v8`/аналог и покажи, что изменил.
