# Задача: аудит структуры БД

Проверь структуру БД (**read-only**) для указанной области.

Через MCP `postgres` / `query_render_postgres` выполняй **только read-only** SQL (SELECT/EXPLAIN, `information_schema`, `pg_indexes`). Найди: отсутствующие индексы под частые запросы, отсутствие FK/констрейнтов/NOT NULL/UNIQUE, потенциальные N+1 (в коде репозиториев), проблемы нормализации, рассинхрон схемы и моделей/миграций, небезопасные миграции. Ничего не изменяй. Формат: объект (`таблица`/`колонка`) или `file:line`, что нашли, первопричина, конкретная починка (DDL/индекс/миграция); severity по влиянию. По значимым находкам — `add_task`. Опирайся на `$database`, `$postgresql`.
