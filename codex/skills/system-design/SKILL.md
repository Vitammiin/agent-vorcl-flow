# Навык: System Design

Проектирование распределённых систем.

- Декомпозиция на сервисы и границы контекстов (bounded contexts)
- Синхронное vs асинхронное взаимодействие, очереди и события
- Масштабирование, кэширование, идемпотентность, отказоустойчивость
- Наблюдаемость: логи, метрики, распределённый трейсинг
