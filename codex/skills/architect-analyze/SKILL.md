# Задача: анализ требований

Проанализируй требования и контекст задачи, которую описал пользователь.

Выдели акторов, ограничения, риски и открытые вопросы. Опирайся на `$system-design`. Структурируй ответ: контекст → варианты → решение → риски → следующие шаги.
