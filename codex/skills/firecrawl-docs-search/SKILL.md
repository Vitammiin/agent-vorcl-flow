# Firecrawl docs search

Проверь CLI help; иначе MCP или POST `/v2/support/docs-search`. Используй только официальные Firecrawl docs/repositories, цитируй прямые URL и отмечай различия версий. Не придумывай отсутствующую CLI-команду.
