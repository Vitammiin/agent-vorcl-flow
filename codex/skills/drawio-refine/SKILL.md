# Задача: доработать существующий .drawio (drawio)

Доработай указанный `.drawio`, не ломая остального (см. `$drawio-diagrams`, `$pmp-diagrams`).

Разбери текущий `mxGraphModel` и внеси изменения: добавь/убери узлы и связи, перекрась под единую семантическую палитру, выровняй по сетке (`gridSize=10`, без наложений), приведи рёбра к ортогональным, улучшь читаемость, добавь легенду если нужна. Сохраняй целостность: уникальные id (не дублируй, `0`/`1` не трогай), у рёбер валидные `source`/`target`, экранирование в подписях, well-formed XML.

После правок `xmllint --noout` и покажи, что изменилось. Отдай обновлённый файл + путь + краткий diff-résumé + какие библиотеки включить при новых фигурах. Опирайся на `$drawio-diagrams`, `$pmp-diagrams`.
