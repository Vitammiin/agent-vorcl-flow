# Задача: безопасная миграция (database)

Спланируй и подготовь миграцию (см. `$database`).

Только **обратимые** миграции по схеме **expand → migrate/backfill → contract** (zero-downtime): сначала совместимое добавление, затем перелив данных батчами, затем удаление старого отдельным шагом. Большие таблицы — без долгих блокировок (`CREATE INDEX CONCURRENTLY`, батч-бэкфилл). Всегда предусмотри `down`/откат. Покажи план (up/down, порядок, влияние на блокировки/время) до применения. **Применение миграции необратимо для данных — только с явным подтверждением человека**; неоднозначные «ок/давай» prod не авторизуют, необратимые активации выноси в PR. Первопричину чини схемой/кодом, а не точечной правкой записей. Опирайся на `$database`, `$postgresql`, `$mongodb`. Для доступа к прод-БД на Render — роль `$render`.
