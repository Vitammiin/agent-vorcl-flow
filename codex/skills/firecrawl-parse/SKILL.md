# Firecrawl parse

Проверь файл и `firecrawl parse --help`; затем CLI → MCP → multipart REST `/v2/parse`. Публичный URL направь в scrape. Не загружай чувствительный документ без подтверждения. Сохрани результат в `.firecrawl/` и укажи ограничения распознавания.
