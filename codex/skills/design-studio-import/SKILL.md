# Импорт источника

Выбери один маршрут `$design-studio`: `import-from-figma.md`, `import-from-github.md` или `import-from-html.md`. Для `.fig` используй offline importer; GitHub исследуй до узкого импорта во временный каталог; сохраняй URL, commit и лицензионные notices.
