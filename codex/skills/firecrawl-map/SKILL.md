# Задача: карта сайта (firecrawl)

Построй карту URL указанного сайта.

Через MCP `firecrawl` выполни `firecrawl_map` — быстро и дёшево собери индексируемые URL. Это разведка **перед** дорогим `crawl`: сгруппируй/отфильтруй URL по разделам, выдели нужные под задачу страницы. Верни список URL (при большом объёме — сгруппированный) и рекомендацию, что скрейпить/краулить дальше. Опирайся на `$web-scraping`.
