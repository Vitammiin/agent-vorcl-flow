## What is this?

Agent-Vorcl-Flow претвара подржаног агента за кодирање у **структурирани инжењерски тим**. Уместо једног генералног асистента, добијате **25 фокусираних подагената** (архитекта, главни архитекта заснован на коду, позадина, фронтенд, Expo инжењер за мобилне уређаје, инжењер за визуелни дизајн, DB инжењер, ревизор интегритета на више језика, картограф архитектуре, оператор ливебоард-а и још много тога), сваки са својим сопственим скиллсласх** и брзим доменом** **MCP алати** који су му потребни. Сваки нетривијалан задатак пролази кроз дисциплиновану **Task Master** петљу — *циљ → задаци → имплементација → верификација → обављено* — тако да се рад планира, прати и преживљава прекиде.

- 🧩 **25 подагента**, 73 вештине, 155 команди
- ⚡ **Инсталација једном командом** за Claude Code, Codex, Cursor и/или Kimi CLI — `npx`
- 🔌 **11 MCP сервера** повезаних (GitHub, Postgres, MongoDB, Redis, Docker, Firecrawl, Vercel, Рендер, систем датотека, Task Master, Mermaid)
- 🔑 **Једна `.env` датотека за сва времена извођења** — кључеви које чита покретач, а не `~/.zshrc`, тако да раде чак и од покретања ГУИ/ИДЕ; нема даљинске АВФ услуге; ливебоард је само за локални хост и ефемеран
- 🤝 **Ради на Claude Code, GPT Codex, Cursor и Kimi CLI** из истог извора

## Quick start

### Requirements
- **Node.js ≥ 18**
- **[Claude Code](https://claude.com/claude-code)**, **[GPT Codex](https://developers.openai.com/codex/cli/)**, **[Cursor](https://cursor.com/)** и/или **[Kimi CLI](https://github.com/MoonshotAI/kimi-cli)**

### Install (one command)

```bash
# Installs adapters for Claude Code, Codex, Cursor, and Kimi CLI:
npx github:Vitammiin/agent-vorcl-flow
```

Циљајте једно време извођења са заставицом:

```bash
npx github:Vitammiin/agent-vorcl-flow --claude   # Claude Code only
npx github:Vitammiin/agent-vorcl-flow --codex    # GPT Codex only
npx github:Vitammiin/agent-vorcl-flow --cursor   # Cursor only
npx github:Vitammiin/agent-vorcl-flow --kimi     # Kimi CLI only
```

Шта ради инсталатер:

| Рунтиме | Акција |
| --- | --- |
| **Дељени слој** | Копира покретач у `~/.config/agent-vorcl-flow/bin/mcp-env.mjs` и креира `~/.config/agent-vorcl-flow/.env` из шаблона (једном) — датотеку са једним кључем за свако време извршавања. |
| **Claude Code** | Региструје овај репо као додатак **маркетплаце** и омогућава додатак (преко `claude plugin …`, са директним `~/.claude/settings.json` резервним). |
| **GPT Codex** | Спаја вештине у `~/.agents/skills` и блокове `config.toml` + `AGENTS.md` у `~/.codex` (идемпотентно, између маркера). |
| **Cursor** | Инсталира вештине у `~/.cursor/skills`, изворне прилагођене подагенте у `~/.cursor/agents` и спаја недостајуће сервере у `~/.cursor/mcp.json`. |
| **Kimi CLI** | Инсталира вештине у `~/.kimi/skills`, изворни Expo прилагођени агент у `~/.kimi/agents`, оба Expo архитектура/UI се повезују са `~/.kimi/config.toml` и спаја MCP сервере. |

> Инсталатер никада не попуњава ваше тајне – он само креира празан `.env` из шаблона. Тамо додајете кључеве (погледајте [Configuration](#configuration-mcp--keys)).

### Update to the latest version

Поново покрените инсталациони програм са ознаком npm `latest`:

```bash
npx --yes agent-vorcl-flow@latest
```

Да бисте ажурирали само једно време извршавања, задржите исту ознаку времена извршавања коју сте користили током инсталације:

```bash
npx --yes agent-vorcl-flow@latest --claude
npx --yes agent-vorcl-flow@latest --codex
npx --yes agent-vorcl-flow@latest --cursor
npx --yes agent-vorcl-flow@latest --kimi
```

Ажурирање прекрива вештине којима се управља Agent-Vorcl-Flow, агенте, куке, покретач и конфигурационе блокове. Одржава ваше постојеће `~/.config/agent-vorcl-flow/.env` и његове тајне непромењене и чува Firecrawl вештине. Поново покрените ажурирани клијент за кодирање (или покрените `/reload-plugins` у Claude Code).

### Alternative installs (Claude Code)

```bash
# Load for the current session only (great for trying it out):
claude --plugin-dir /path/to/agent-vorcl-flow

# Or install persistently from a local marketplace:
/plugin marketplace add /path/to/agent-vorcl-flow
/plugin install agent-vorcl-flow
```

Након инсталације, **поново покрените Claude Code** (или покрените `/reload-plugins` у отвореној сесији) да бисте учитали агенте.

## How to use

Примери у овом одељку користе синтаксу Claude Code; погледајте мапирања [Cursor](#cursor) и [GPT Codex](#gpt-codex) у наставку за њихову изворну синтаксу. У Claude Code постоје **три начина** за позивање тима.

### 1. Universal entry point — just state a goal
```text
/vorcl add a shopping cart to checkout
/audit .
/init-code .
```
`/vorcl` открива који подагент треба да буде власник посла и покреће цео Task Master циклус. `/audit` аутоматски открива позадину, фронтенд, мобилни уређај, податке и инфраструктуру и пише `PROJECT_AUDIT.md` заснован на доказима користећи све релевантне улоге. `/init-code` статички чита спремиште и креира `PROJECT_DESCRIPTION.md` заснован на доказима без извршавања кода пројекта. Једном када та датотека постоји, свака улога за модификовање мора да одржава синхронизоване одељке на које утиче; доказано померање описа блокира завршетак задатка.

### 2. Talk to a specific sub-agent
```text
@agent-vorcl-flow:architect  design billing for a SaaS
@agent-vorcl-flow:backend    add a POST /invoices endpoint
```

### 3. Run a specific slash command
```text
/backend:create-api   POST /invoices
/analyzer:audit       src/
/screenshot:convert   ./mockups/dashboard.png  react
```

Сваки агент такође има сопствену улазну тачку `/<agent>:vorcl` која покреће петљу Task Master опсежену том агенту.

### The Task Master loop
Сваки нетривијалан задатак тече кроз **Task Master** (`task-master-ai`):

```text
goal → tasks (parse_prd / add_task) → next_task → get_task → expand_task
     → implement → verify (testStrategy) → set_task_status done
```Ово одржава рад планираним, контролисаним и настављивим — ништа се не проглашава „урађеним“ без проласка корака верификације.

**Неколико ствари које вреди знати:**
- **Фронтенд увек разговара са правим API.** Позадинска OpenAPI спецификација је једини извор истине; типови се генеришу из њега (`openapi-typescript` + `openapi-fetch`). Нема ругања у производном путу.
- **`database` мутације захтевају експлицитну потврду.** Аналитика је само за читање; Промене шема/података (ДДЛ/ДМЛ/миграције) се никада не покрећу без вашег одобрења.
- **`resilience` шаље сигурносну куку.** `PostToolUse` кука која не блокира (`catch-guard.js`) нежно означава празне `catch {}` блокове у датотекама које сте управо уредили.
- **`archmap` никада не црпи из маште.** Екстракција и приказивање су стриктно одвојени: скрипте без зависности воде репо у `architecture.json` (базе података са стварним ФК кардиналношћу, API руте, АИ агенти са њиховим моделима/алатима/меморијом, графиком увоза, рендером), и само из тог дијаграма. Све што ЛЛМ додаје без провереног `file:line` је насилно означено `inferred:true` и исцртано испрекидано.
- **`principal-architect` је потпуни ток рада за објављивање архитектуре.** Ради у било ком спремишту да покрене агента, игнорише Маркдовн тврдње као доказ топологије, користи у пакету ВАСМ за чување стабала ван мреже за ТС/ЈС, Питхон, Го, Јава, Ц#, Руст, ПХП, Руби, Котлин и Свифт, пише   производи први дељени модел. HTML, PDF, изворни драв.ио и Mermaid Л0–Л4 који се може копирати. `update` врши потпуно поновно скенирање и чува напомене и датотеке којима се не управља.
- **`pinpoint` проналази, никада не ствара.** Узимајући снимак екрана покренуте апликације, мапира екран у прави код — компоненту, руту, тачну контролу и логику иза ње — и предаје уређивање `frontend`/`backend`. Ради на ономе што већ постоји (обрнуто од `screenshot`).
- **`visual-research` верификује уместо нагађања.** Третира снимак екрана као доказ, потврђује званични домен и документе, проверава тренутне податке сајта и означава могуће „пецање“ или застареле вредности.
- **`i18n` примењује „нулто језичко кодирање“.** Агенти прво детектују да ли је пројекат вишејезичан и прилагођавају се — стрингови окренути кориснику пролазе кроз слој за превођење (нект-интл / реацт-и18нект / и18нект), никада инлине.

## Command referenceСвака наредба испод је команда косе црте. `<…>` означава ваш унос.

### `/vorcl` — universal router
| Цомманд | Шта ради |
| --- | --- |
| `/vorcl <goal>` | Претвара било који циљ у задатке и усмерава га до правог подагента, а затим покреће цео циклус до краја. |
| `/audit [path] [focus]` | Дубока ревизија са више улога само за читање → откривени системи, налази безбедности/ЦВЕ/отпорности, циљна архитектура и фазни `PROJECT_AUDIT.md`. |
| `/init-code [path] [--update]` | Откривање статичне кодне базе → засновано на доказима `PROJECT_DESCRIPTION.md`; код пројекта се никада не извршава. |

### 🔵 architect — architecture

## Configuration (MCP & keys)

Пакет нема **нема удаљену позадину или базу података**. Опциони ливебоард је процес у меморији само за локални хост. MCP серверима су потребни токени, а **сваки корисник даје своје**. Да би ово функционисало на идентичан начин на **Claude Code, Codex, Cursor и Kimi CLI** — и било да покрећете са терминала или са Доцк-а / Спотлигхт-а / ИДЕ-а — сваки стдио MCP сервер се покреће преко малог покретача (`bin/mcp-env.mjs`) који чита ваше кључеве из **једне датотеке**:

```
~/.config/agent-vorcl-flow/.env          # Windows: %APPDATA%\agent-vorcl-flow\.env
```

Инсталатер га креира од [`.env.example`](../.env.example). Отворите га и попуните само кључеве које користите:

```dotenv
ANTHROPIC_API_KEY=      # Task Master main provider: Claude
OPENAI_API_KEY=         # alternative main provider: GPT
PERPLEXITY_API_KEY=     # optional: Task Master research mode
FIRECRAWL_API_KEY=      # firecrawl web research
GITHUB_TOKEN=           # github MCP

# For the `database` agent — these point at YOUR project's DB, not the plugin's:
MONGODB_URI=            # mongodb://user:pass@host:27017/db
REDIS_URL=              # redis://host:6379
POSTGRES_URL=           # postgres://user:pass@host:5432/db
```

> **Зашто се покретач уместо `~/.zshrc`?** Енв-вар проширење разликује по времену извршавања (`${VAR:-}` у Claude, `${env:VAR}` у Cursor, литерали у Codex/Kimi) и свако време извршавања чита само окружење **у којем је** покренуто. ГУИ / ИДЕ покретања на мацОС-у се не повезују са сервером, тако да се не извозе у изворни кључ класична грешка „MCP енв нот сет“. Читање из једне `.env` датотеке уклања оба проблема одједном.

**Предност** (касније победе): дељени `~/.config/agent-vorcl-flow/.env` → а `./.env` у корену пројекта → прави `export` у вашој љусци. Чувајте глобалне кључеве у дељеној датотеци, замените по пројекту (нпр. другачији `MONGODB_URI`) пројектом `.env`, а оригинални извоз љуске и даље побеђује за CLI покретања. Можете усмерити покретач на другу датотеку помоћу `AGENT_VORCL_ENV_FILE=/path/.env`.Сервер коме недостаје потребан кључ једноставно се **не покреће** — видећете `[agent-vorcl-flow] MCP «…» is not configured: …` у једном реду у евиденцији MCP рунтиме-а, а сваки други сервер наставља да ради. Додајте кључ на `.env` и поново покрените. (Можете да задржите имена `GITHUB_TOKEN`/`MONGODB_URI` — покретач их мапира на `GITHUB_PERSONAL_ACCESS_TOKEN`/`MDB_MCP_CONNECTION_STRING` које сервери очекују.)

> ⚠ **Обавезно за команде Task Master које покреће АИ:** конфигуришите најмање једног изабраног добављача — `ANTHROPIC_API_KEY` за Claude, `OPENAI_API_KEY` за ГПТ или Codex CLI ОАутх. Без акредитива за модел изабран у `.taskmaster/config.json`, `/vorcl` не може да генерише или прошири задатке.

Одаберите који Task Master провајдер заправо покреће генерисање; само тастери не бирају модел:

```bash
/task-master:provider anthropic <model-id>   # Claude via ANTHROPIC_API_KEY
/task-master:provider openai <model-id>      # GPT via OPENAI_API_KEY
/task-master:provider codex-cli <model-id>   # ChatGPT OAuth via `codex login`
```

Команда користи званични ток `task-master models` и чува само избор модела у `.taskmaster/config.json`. `PERPLEXITY_API_KEY` је опционо и потребно само када је Перплекити изабран као модел истраживања.

Удаљени **верцел** и **рендер** сервери користе ОАутх (ауторизујте помоћу `/mcp` у прегледачу). За Рендер у хеадлесс/CI, подесите `RENDER_API_KEY` у свом окружењу и додајте унос заглавља Беарер на тај сервер за време извршавања.

## Project structure

```text
.claude-plugin/plugin.json      # plugin manifest
.claude-plugin/marketplace.json # local marketplace (for install)
agents/       26 sub-agent definitions (*.md)
skills/       <skill>/SKILL.md            (75 skills; some ship references, scripts, tests or HTML assets)
commands/     <namespace>/<command>.md    (154 commands, /namespace:command, including /vorcl and /audit)
hooks/        hooks.json + SessionStart + PostToolUse guards (empty catch, Pino logging, Expo architecture/UI boundaries)
.mcp.json     github, filesystem, postgres, mongodb, redis, docker, firecrawl, vercel, render, task-master, mermaid
.env.example  template for ~/.config/agent-vorcl-flow/.env (single key file for all runtimes)
translations/ localized README files (21 translations)
bin/          install.mjs (the npx installer) + mcp-env.mjs (cross-runtime MCP launcher / .env loader)
codex/        GPT Codex adapter (skills + config.toml + install.sh)
cursor/       Cursor adapter (MCP template + installation notes)
kimi/         Kimi CLI adapter (skills install + Expo agent/hook + MCP)
```

**Како се то уклапа:** `agents/*.md` декларишете улогу и, у првом реду `skills:`, приложите вештине → вештине у `skills/*/SKILL.md` се аутоматски учитавају према опису → `commands/<agent>/*.md` обезбеђују брзе `/agent:command` пречице које делегирају подагенту → `.mcp.json` даје агентима своје алате, од којих сваки почиње преко `bin/mcp-env.mjs` који дели тајне податке. `SessionStart` кука говори Claude да су агенти доступни.
