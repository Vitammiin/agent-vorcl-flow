---
description: Рекурсивный обход раздела/сайта через Firecrawl (firecrawl). Use when нужен контент МНОГИХ страниц раздела/сайта (дорого, всегда с limit); одна страница → /firecrawl:scrape, только список URL → /firecrawl:map
argument-hint: "<URL раздела/сайта> [limit; что собрать]"
allowed-tools: Read, Write, Bash, Grep, Glob, WebFetch
---

Обойди сайт/раздел и собери контент: **$ARGUMENTS**.

Сначала (если объём неизвестен) прикинь охват через `firecrawl_map`, затем через MCP `firecrawl` запусти `firecrawl_crawl` — **всегда** с разумным `limit` и, при необходимости, с ограничением по путям. Краул асинхронный: опрашивай `firecrawl_check_crawl_status` до готовности. `formats: ["markdown"]`, `onlyMainContent`. Помни: большой краул — дорого (кредиты) и медленно, не запускай без лимита; перед большим обходом (limit > 50 или сайт целиком) назови ожидаемый объём страниц и **дождись явного подтверждения человека**. Верни собранные страницы (markdown) — у каждой её URL-источник — и краткую сводку. Опирайся на навык `web-scraping`. Делегируй субагенту `firecrawl`.
