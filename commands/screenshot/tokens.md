Извлеки из скриншота единую систему дизайн-токенов: **$ARGUMENTS**.

Открой изображение через Read и собери токены как **семантические** CSS-переменные в блоке `@theme` (Tailwind v4, CSS-first):
- **Цвета:** сними точные hex, переведи в **OKLCH** и назови по роли (`--color-primary`, `--color-surface`, `--color-border`, `--color-muted`, `--color-danger`…), а не «магическими» литералами. Учти тёмную тему, если видна.
- **Типографика:** семейства (`--font-*`), шкала кегля, насыщенность, межстрочный, трекинг.
- **Spacing:** восстанови единую шкалу отступов (`--spacing-*`), а не случайные px.
- **Радиусы, тени, градиенты, брейкпоинты** — тоже в токены (`--radius-*`, `--shadow-*`, `--breakpoint-*`).

Выдай готовый блок `@theme` (`@import "tailwindcss"; @theme { … }`) + короткую таблицу «токен → где на макете». Семантические имена, не значения по месту. Опирайся на навыки `tailwind`, `screenshot-to-code`. Делегируй субагенту `screenshot`.
