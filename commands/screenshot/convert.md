Сгенерируй полный код по скриншоту: **$ARGUMENTS**.

Открой изображение через Read и разбери: layout (grid/flex), компоненты (повторы — в переиспользуемые), визуальные детали (цвета, типографика, spacing, радиусы, тени). **Фреймворк:** если не указан — по умолчанию React + Tailwind v4 (простая статика — семантический HTML/CSS); поддержи также Vue / Next.js по запросу.

Требования: **семантический HTML** (`header`/`nav`/`main`/`section`/`button`/`label`, не «div-суп»); **точные цвета** — сними hex со скриншота и объяви семантическими токенами в `@theme` (OKLCH); **spacing и пропорции** по макету; варианты компонента через `cva`, классы через `cn`; типизированные пропсы (`any` запрещён); **адаптивность** (rem/%/`clamp()`, брейкпоинты/container queries); **a11y** (alt, `aria-*`, видимый focus, контраст WCAG).

**Материализуй** результат как файлы в рабочем каталоге/проекте пользователя (Write) и отдай пути — не оставляй код только текстом в ответе. Перед выдачей **проверь, что код запускается**: `npm run dev`/`npm run build` (для статики — открытие HTML) проходит без ошибок; только запускаемый артефакт = готово. Отдай **все файлы + пути**, структуру, как запустить, результат проверки и краткие заметки о допущениях. Неоднозначное помечай комментарием и предлагай альтернативу. Опирайся на навыки `screenshot-to-code`, `tailwind`, `react`, `nextjs`, `typescript`. Делегируй субагенту `screenshot`.
