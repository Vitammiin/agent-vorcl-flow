Вычисли конкретный контрол, с которым работает пользователь, и его обработчик: **$ARGUMENTS**.

Открой скриншот через Read. Найди компонент экрана, затем среди него — **конкретный** элемент (кнопку/поле/иконку) по тексту/`aria-label`/иконке/позиции относительно соседей. Найди его обработчик (`onClick`/`onSubmit`/`onChange`) и куда он ведёт (локальный хендлер, экшен стора, мутация). Несколько похожих контролов — раздели по различающему признаку (текст, `variant`, ближайший заголовок), не угадывай молча.

Отдай: элемент + обработчик с точностью до **`file:line`** + фрагмент; при неоднозначности — кандидаты с различием. Только чтение — правку делегируй. Опирайся на навыки `ui-source-mapping`, `react`, `typescript`, `state-management`. Делегируй субагенту `pinpoint`.
